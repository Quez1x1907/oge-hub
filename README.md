# Пятёрка — тренажёр ОГЭ

Бесплатный веб-тренажёр для подготовки 9-классников к ОГЭ по **математике, русскому языку, обществознанию и информатике**. Полностью статический сайт — без сервера и сборки: прогресс хранится в браузере (localStorage).

## Возможности

- **137 заданий** в формате реального ОГЭ 2026/27 (по демоверсиям ФИПИ):
  - 🔢 Математика — 40: числа, выражения, уравнения, неравенства, функции, последовательности, геометрия, проценты, вероятность, текстовые задачи, 2-я часть
  - 📝 Русский язык — 32: ударения, Н/НН, З/С, ПРИ/ПРЕ, части речи, лексика, синтаксис, пунктуация, стили, грамматика диктанта
  - ⚖️ Обществознание — 32: экономика, право, общество, политика, социальные сферы, информация
  - 💻 Информатика — 33: объём информации, системы счисления, кодирование, алгоритмы, Python, БД, сети, логика
- Мгновенная проверка ответов + **пошаговые разборы** (для сложных заданий — пословный план решения)
- Список **«разбор ошибок»**: неверно решённые задания возвращаются в работу
- **Короткие варианты по таймеру** — имитация экзамена с навигатором, оценкой по шкале 5/4/3/2 и разбивкой по темам
- **Статистика**: точность по предметам и темам, активность за 14 дней, серия дней, слабые темы, экспорт прогресса в JSON
- **План подготовки** на весь учебный год (5 этапов: фундамент → углубление → практика → спринт → день Х) с чек-листами
- **ИИ-репетитор**: офлайн-режим (пошаговый разбор заданий из базы, поиск похожих задач, проверка твоих ответов) и онлайн-режим (подключение собственного OpenAI-совместимого API — ключ хранится только в браузере)
- Светлая/тёмная тема, адаптивная вёрстка

## Запуск локально

```bash
cd oge-hub
python3 -m http.server 8080
# открыть http://localhost:8080
```

Подойдёт любой статический сервер: `npx serve`, Live Server в VS Code и т.п.

## Публикация на GitHub Pages

1. Запушить репозиторий на GitHub.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.
3. Через пару минут сайт доступен по адресу `https://<username>.github.io/<имя-репо>/`.

> Прогресс каждого ученика хранится в его браузере (localStorage на домене сайта) — бэкенд не нужен.

## Структура проекта

```
oge-hub/
├── index.html          # скелет SPA (все экраны рендерятся в #view)
├── css/style.css       # стили, светлая/тёмная тема
└── js/
    ├── store.js        # хранилище в localStorage: ответы, история, план, варианты
    ├── engine.js       # проверка ответов, перемешивание, canvas-графики (без библиотек)
    ├── ai.js           # ИИ-репетитор: офлайн-разбор + онлайн (свой API)
    ├── app.js          # роутер и экраны: главная, предметы, тренировка, вариант, статистика, план
    └── data/
        ├── themes.js   # темы предметов, план подготовки, советы дня
        ├── math.js     # банк заданий: математика
        ├── russian.js  # банк заданий: русский язык
        ├── social.js   # банк заданий: обществознание
        └── informatics.js # банк заданий: информатика
```

## Как добавить задание

Формат задания в `js/data/<предмет>.js`:

```js
{
  id: 'm41',              // уникальный id (m — математика, r — русский, s — общество, i — информатика)
  theme: 'eq',            // тема из themes.js (определяет статистику)
  diff: 2,                // 1 — базовое, 2 — повышенное, 3 — сложное
  type: 'choice',         // 'choice' | 'number' | 'text'
  prompt: 'Решите уравнение: 3x − 7 = 2x + 5',
  options: ['11', '12', '13', '14'],        // только для type: 'choice'
  answer: 1,              // choice: индекс верного варианта (с 0); number: значение; text: ''
  exp: '3x − 2x = 5 + 7 → x = 12.',         // разбор, показывается после проверки
  steps: ['3x − 7 = 2x + 5', '3x − 2x = 5 + 7', 'x = 12']  // необязательно: пошаговый разбор для ИИ
}
```

Нюансы:

- `number` — принимает запятую и точку как разделители; массив `answer: [2, 8]` означает «оба значения».
- `text` — автопроверка списком `accept: ['√74', 'корень из 74']` (сравнение без учёта регистра и пробелов) **или** самооценка ученика (без `accept` — кнопки 0 / 0,5 / 1).
- Новая тема — добавить `{ id, name }` в соответствующий предмет в `js/data/themes.js`; задания с неизвестной темой не попадут в статистику.
- Простейшая проверка банка:

```bash
node -e "
global.window = {};
['themes','math','russian','social','informatics'].forEach(m => require('./js/data/' + m + '.js'));
for (const sub of Object.keys(window.OGE_DATA)) console.log(sub, window.OGE_DATA[sub].length);
"
```
